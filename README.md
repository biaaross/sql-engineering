# SQL Engineering

A structured SQL repository focused on advanced querying, database optimization, performance analysis, and practical SQL projects.

## Overview

This repository documents my SQL learning and engineering work, with a focus on writing efficient queries, understanding database execution plans, optimizing SQL performance, and solving realistic data problems.

## Repository Structure

### `docs/`

Technical documentation covering SQL concepts, advanced SQL topics, indexing, query optimization, and database performance.

### `performance-lab/`

Practical SQL performance experiments and optimization case studies.

Each case focuses on:

* Identifying slow queries
* Analyzing execution plans
* Finding performance bottlenecks
* Designing appropriate indexes
* Optimizing queries
* Measuring performance before and after optimization

### `projects/`

Realistic SQL projects designed to apply SQL knowledge to practical data problems.

Projects include database design, data analysis, complex queries, and performance considerations.
